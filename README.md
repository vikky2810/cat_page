# Cat Corner Web Page

A simple and friendly cat-themed web page built with **HTML, CSS, and JavaScript**.

## Features

- Clean, centered cat card layout
- "Cat Fact of the Moment" section powered by a **public API**
- Button that fetches a fresh cat fact each click
- Loading state and graceful error handling when the API is unavailable
- Short list of reasons why cats are awesome

## Project Structure

- `index.html` — page structure and content
- `styles.css` — visual styling and layout
- `script.js` — API-based cat fact fetching logic

## API Used

- Endpoint: `https://catfact.ninja/fact`
- Type: public read-only cat fact API

## How to Run

1. Clone or download this project.
2. Open `index.html` in your browser.
3. Click **Show me a cat fact** to load a fact from the API.

No build tools or dependencies are required.

## Customization Ideas

- Add a "Fact history" section that stores previously fetched facts.
- Add cat photos from a second public API.
- Add dark mode with an alternate CSS palette.

Enjoy the cats! 🐾
